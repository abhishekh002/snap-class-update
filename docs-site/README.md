# SnapClass documentation site

Open `index.html` in a browser, or serve this folder locally from the project root:

```powershell
python -m http.server 8000 --directory docs-site
```

Then visit `http://localhost:8000`. The page is static and has no install step. SVG diagrams and the PDF edition are in `assets/`. GitHub Pages is configured to deploy this repository from the `main` branch.
